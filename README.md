# VST3PlusVocal

Clean JUCE 8 VST3 baseline for Windows / FL Studio.

This build intentionally contains only:
- stereo/mono audio passthrough
- minimal native JUCE editor
- no DSP, AI, file loading or external dependencies beyond JUCE
- GitHub Actions Windows build
- exact product name: VST3PlusVocal
- vendor: 29YURO

Install the complete `VST3PlusVocal.vst3` bundle into:
`C:\Program Files\Common Files\VST3\`

Then rescan plugins with errors in FL Studio.
